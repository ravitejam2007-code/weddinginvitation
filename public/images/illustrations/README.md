# Invitation illustration assets

These original SVG assets are authored for this invitation. They use the shared ivory, sage, antique-gold, and blush palette and can be edited as independent layers.

| Asset | Intended use |
| --- | --- |
| `paper-grain.svg` | Repeatable, low-contrast page-paper texture |
| `envelope-pocket.svg` | Separate front-pocket folds for the closed envelope |
| `envelope-flap.svg` | Top flap artwork; CSS owns the open/close transform |
| `envelope-lining.svg` | Repeating inner envelope and flap lining |
| `wax-seal-base.svg` | Seal body and inset rim, behind the approved motif component |
| `floral-corner.svg` | Compact corner ornament for the envelope scene |
| `floral-sprig.svg` | Vertical botanical decoration for narrow stationery edges |
| `floral-bouquet.svg` | Larger bouquet artwork for invitation or closing compositions |
